# বাঁশ খেয়েও বস 3D — v0.1

Godot 4.3 Android mini-test game.

Upload the **contents of this ZIP** to the root of a new GitHub repository, including the hidden `.github` directory. Then open Actions > Bansh Kheyeo Boss 3D v0.1 APK > Run workflow.

The APK is a debug test build, not a release. Build and device testing have not yet been completed.
